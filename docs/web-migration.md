## 확인한 결과

- TypeScript 타입 검사와 웹 프로덕션 빌드 통과.
- 비특권 사용자·init·캐시 경로를 갖춘 최종 환경에서 전체 core 하위 패키지, RPC, RPC 바인딩, 신규 서버와 두 실행점의 Go 검증 통과.
- 원본 웹 테스트와 추가 브라우저 전송 테스트: 32개 파일, 519개 테스트 통과(Node 실행).
- 신규 서버 테스트: 인증·CSRF·Origin·허용 API·revision 필수·로그아웃·비밀정보 암호화·변조·키 권한·TOTP 표준 벡터 검증.
- HTTP → 원본 IMAP/SMTP 테스트 서버 경로로 메일 읽기·HTML 스크립트 격리·초안 충돌 거부·중복 발송 방지·SMTP 1회 수신 검증 통과.
- ARM64 Docker 이미지 빌드와 비특권 컨테이너 실행 통과. 컨테이너에서 MFA 로그인·메일 API·MCP 초기화·health 응답 200 확인. 현재 호스트 루프백 127.0.0.1:8878에서 실행 중.
- 실제 Go HTTP 프로세스에서 로그인, 메일 목록, 라벨·서명·규칙 생성/수정/삭제, 모의 OpenAI 호환 서버에 대한 AI 스트리밍과 대화 저장 확인. 실제 메일 발송이나 유료 AI 호출은 하지 않음.
- 초기 root 컨테이너에서 실패했던 자식 프로세스 정리·삭제 불가 캐시 테스트 3건은 비특권 사용자·init·쓰기 가능한 캐시 환경에서 통과.

실계정 연결, 실기기 반응형, 화면별 시각 동등성과 대규모 성능은 아직 검증되지 않았다. 이 상태를 원본과 완전히 동일한 제품이라고 표현하지 않는다.
